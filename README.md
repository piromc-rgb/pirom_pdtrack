# PDTrack - ระบบติดตามเป้าหมายการส่งมอบรายเครื่องจักร (Machine-Centric Delivery Tracker)

แอปพลิเคชันสำหรับติดตามสถานะและเป้าหมายการส่งมอบชิ้นส่วน/อะไหล่เครื่องจักร โดยจัดกลุ่มและใช้ **"ชื่อเครื่องจักร" (Machine Name/Code)** เป็นดัชนีหลัก (Index) เชื่อมโยงข้อมูลแบบสด (Live Sync) จาก Google Sheets:
`https://docs.google.com/spreadsheets/d/1l5FbiznQNUhIpUNuma9iivKzYvcaCTiL7Z_9mDcCijE/edit?gid=472754949#gid=472754949`

## ฟีเจอร์หลัก (Key Features)

1. **ดัชนีเครื่องจักร (Machine-Indexed Dashboard)**:
   - แสดงรายชื่อเครื่องจักรทั้งหมด (เช่น `MDPB-26-0063`, `MDPB-26-0099`, `MDPB-26-0112`, `MDPB-26-0139`, `MDPB-26-0154` ฯลฯ)
   - แต่ละเครื่องจักรมีการคำนวณ **% ความคืบหน้าการส่งมอบ**, จำนวนชิ้นส่วนที่ส่งแล้ว/ทั้งหมด, จำนวนชิ้นรวม (Qty)
   - ป้ายสถานะแจ้งเตือนอัตโนมัติ: **ส่งมอบครบถ้วน (100%)**, **เกินกำหนดส่ง (Overdue)**, **ใกล้ถึงกำหนดส่ง (Due Soon)**, **อยู่ระหว่างดำเนินการ (In Progress)**

2. **หน้ารายละเอียดเจาะลึกรายเครื่องจักร (Machine Drilldown Modal)**:
   - เมื่อคลิกที่เครื่องจักร จะเปิดหน้ารายการชิ้นส่วนทั้งหมดของเครื่องจักรนั้น
   - แสดง **ประวัติการปรับเป้าหมายส่งมอบ (เป้าหมาย 1 $\rightarrow$ 2 $\rightarrow$ 3 $\rightarrow$ 4 $\rightarrow$ 5 $\rightarrow$ ล่าสุด)** พร้อมขีดฆ่าเป้าหมายเดิมเพื่อให้เห็นการเลื่อนกำหนดการอย่างชัดเจน
   - ตารางแสดง: เลขที่ Item, ชื่อ Item, Qty, Production Order, PO/PR, วันที่แจ้งทำ, สถานะ (ส่งแล้ว / รอส่ง), หมายเหตุจัดส่ง
   - ปุ่ม **ส่งออก CSV (Export CSV)** แยกเฉพาะเครื่องจักรนั้นๆ

3. **กำหนดการส่งมอบตามลำดับเวลา (Delivery Schedule Timeline)**:
   - จัดกลุ่มตามเป้าหมายวันส่งมอบล่าสุด (เรียงตามลำดับเวลา)
   - ระบุชัดเจนว่างวดวันที่ใด มีเครื่องจักรใดบ้างที่ต้องส่งมอบ และสถานะส่งแล้วหรือค้างส่ง

4. **ตารางชิ้นส่วนทั้งหมด (Master Items List)**:
   - ค้นหาและกรองจาก 333 รายการทั้งหมด
   - กรองแยกตามเครื่องจักร, โครงการ, สถานะ, หรือคำค้นหา
   - แบ่งหน้า (Pagination) และรองรับการส่งออก CSV ข้อมูลทั้งหมด

5. **การวิเคราะห์และความเสี่ยง (Analytics View)**:
   - ลำดับความคืบหน้าของทุกเครื่องจักร
   - รายชื่อเครื่องจักรที่มีความเสี่ยงเกินกำหนด (Overdue Rankings)
   - สรุปสัดส่วนตามโครงการ (Project Distribution)

6. **Live Google Sheet Sync & Offline Cache**:
   - เชื่อมต่อดึงข้อมูลสดจาก Google Sheet ทันทีผ่านปุ่ม **"รีเฟรช"**
   - มีระบบ Cache บันทึกไว้ในเครื่อง เมื่อไม่มีสัญญาณอินเทอร์เน็ตยังสามารถเปิดใช้งานได้สมบูรณ์
   - เมนู **"ตั้งค่า"** สำหรับปรับเปลี่ยน URL Google Sheet หรือทดสอบการเชื่อมต่อ

## วิธีการรันระบบ (How to Run)

### พัฒนาและเปิดใช้งาน (Development Server)
```bash
cd d:\PDtrack
npm run dev
```
เปิดเว็บบราวเซอร์ไปที่: `http://localhost:3000`

### การสร้าง Production Build
```bash
npm run build
```
ไฟล์ production พร้อม deploy จะอยู่ในโฟลเดอร์ `dist/`
